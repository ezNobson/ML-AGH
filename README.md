# ML-AGH

This repository contains a collection of **Jupyter Notebooks** and projects developed during the **Machine Learning** course at **AGH University of Science and Technology**.

## 📋 Overview
The projects focus on the practical implementation of various machine learning algorithms, data preprocessing techniques, and model evaluation strategies. Most of the work was conducted using **Google Colab**.

## 📂 Contents
* **Lab Assignments:** Weekly exercises covering core ML concepts.
* **Practical Projects:** End-to-end implementations of ML pipelines.
* **Topics covered:**
    * Linear and Logistic Regression
    * Decision Trees and Random Forests
    * Support Vector Machines (SVM)
    * Neural Networks & Deep Learning
    * Clustering and Dimensionality Reduction (PCA, k-means)
    * Feature Engineering and Data Cleaning

## 🚀 Tech Stack
* **Language:** Python 3
* **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn, TensorFlow/PyTorch.
* **Environment:** Google Colab / Jupyter Notebook

## 🛠 How to Use
1. **Directly in Colab:** You can open any `.ipynb` file and use the "Open in Colab" button (if available) or upload the file to your Google Drive.
2. **Locally:** ```bash
   git clone [https://github.com/YOUR_USERNAME/ML-AGH.git](https://github.com/YOUR_USERNAME/ML-AGH.git)
   cd ML-AGH
   pip install -r requirements.txt # If you create one
   jupyter notebook
   ```
**Created as part of the Machine Learning curriculum at AGH UST.**
